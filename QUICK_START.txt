OIL SENTINEL — Free satellite + EIA oil storage dashboard

1. Open the included Oil-Sentinel-Preview.html to see a historical demo.
2. Create a FREE PUBLIC GitHub repository named oil-sentinel.
3. Upload the CONTENTS of the oil-sentinel project folder (not the ZIP itself).
4. Repository Settings > Pages > Source > GitHub Actions.
5. Actions > Refresh oil intelligence and deploy iPhone app > Run workflow.
6. On your iPhone open https://YOUR-USERNAME.github.io/oil-sentinel/
7. Safari Share > Add to Home Screen.
8. Open the app's Siri & iPhone tab; create the Oil Check shortcut.

Full instructions: README.md and IPHONE_SETUP.md.

IMPORTANT: The included sample is from 2026-10-30, not live data.
Sentinel-2 DOES NOT accurately measure floating-roof tank fill heights.
The GitHub workflow and public EIA/STAC sources must run online to refresh data.
